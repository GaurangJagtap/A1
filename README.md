## Project Overview
This project demonstrates dataset versioning using **Data Version Control (DVC)** coupled with **Git**.
While Git tracks project source code, configuration files, and DVC pointer files (`.dvc`), DVC tracks and versions the underlying large datasets without bloating the Git repository.

## Repository Structure
```
DatasetVersioning/
│
├── .dvc/                   # DVC configuration and internal metadata
│   ├── .gitignore
│   └── config
├── .dvcignore              # DVC ignore rules
├── .gitignore              # Git ignore file (prevents tracking raw dataset)
├── data/
│   ├── student.csv         # Actual dataset (tracked by DVC)
│   ├── .gitignore          # Automatically generated by DVC to ignore student.csv
│   └── student.csv.dvc     # DVC pointer/metadata file tracked by Git
├── README.md               # Project documentation
└── answers.md              # Detailed answers to Reflection Questions (Part H)
```

## Setup & Execution Commands
1. **Initialize Git and DVC:**
   ```bash
   git init
   dvc init
   git commit -m "Initialize Git and DVC"
   ```

2. **Track Dataset with DVC (Version 1):**
   ```bash
   dvc add data/student.csv
   git add data/student.csv.dvc data/.gitignore
   git commit -m "Add student dataset v1 with DVC"
   ```

3. **Update Dataset (Version 2):**
   ```bash
   # Modify data/student.csv
   dvc add data/student.csv
   git add data/student.csv.dvc
   git commit -m "Update dataset to v2 (added 3, updated 1, removed 1)"
   ```

4. **Restore Previous Dataset Version:**
   ```bash
   git checkout HEAD~1 data/student.csv.dvc
   dvc checkout
   ```

5. **Local Remote Storage:**
   ```bash
   dvc remote add -d localstorage ../dvc-storage
   dvc push
   ```
